# DREXIAN Student Widget

Native Android home-screen widget for a student timetable.

## Features
- Clock and date
- Next class, time, and room
- Today's timetable
- Editable assignment and due-date reminder
- Editable exam reminder

## Build APK
GitHub Actions builds a debug APK on every push to `main`. Open the **Actions** tab and download the artifact named **DREXIAN-STUDENT-WIDGET-APK** after a successful run.

## Install on Samsung
Install the downloaded APK, then long-press the Home Screen > Widgets > DREXIAN Student Widget > drag the 4x3 widget onto the screen.

Assignment and exam details are entered manually in the app. The timetable is preloaded from the semester schedule previously supplied.
